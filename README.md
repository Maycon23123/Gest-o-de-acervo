# Gestor-de-acervo

# Sobre o projeto:
É um projeto que utilizei Next JS, tailwindcss e Shadcn ui.
Não tem muita coisa, pois não tenho muita habilidade em nenhum deles, e foi minha primeira vez os usando.

**Pastas criadas/alteradas:**
Components/item: Aqui ficam os componentes dos itens:
- item-card: Esse componente serve para definir e estilizar os cards dos itens, para que todos sigam um padrão.
- item-form: Serve como o formulário para criar novos itens, para o estilizar, na parte do typescript não sou muito bom e foi a parte que menos estudei, mas consegui fazer funcionar dessa forma.
- item-list: Serve para colocar os itens na ordem em que foram criados e para definir se tem itens para determinado usuário.

Components/sidebar: Não tem muito motivo de uso, foi mais a minha forma de treinar o Tailwind.
Components/ui: Aqui ficam os componentes do  Shadcn ui.
Components/user:
- user-cria: Antes de postar, eu estava pensando em fazer um jeito de adicionar usuários em uma janela diferente, mas não soube como fazer isso. No futuro, possivelmente eu termine o que está escrito aqui.
- user-selector: Tem apenas 2 usuários a escolher entre eles para poder ver os itens.

**Mocks:**
- Como o nome da pasta já indica, eu usei a forma de mocks (dados pré-definidos).
 
**types:**
- Aqui ficam os tipos de dados do user e item.

**services:**
- item-service: Aqui ficam as funções para criar, deletar, visualizar e ver apenas aqueles de um usuário específico.
- user-services: Assim como o do item, aqui tem as funções do usuário, tem certas funções que não foram utilizadas pois, como expliquei acima, eu não consegui fazer de forma certa e não tinha muito conhecimento de typescript.

**App:**
- layout: Onde eu treinei meus conhecimentos de Tailwind (mesmo que não sejam muitos).
- page: Onde tudo se encontra, juntei funções junto com outras funções para diminuir o tamanho do código (não sei se isso é o apropriado).
- Logo em seguida, usei os componentes que tinha criado anteriormente.

Obs: Sei que não é muita coisa, mas eu tive uma boa dificuldade, mas por conta do TypeScript, que fez eu sofrer bastante.
